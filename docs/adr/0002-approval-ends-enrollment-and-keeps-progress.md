# Approval ends the enrollment and keeps progress

Approving a refund request removes the learner's enrollment in the same transaction, so the course ends at the decision and not when a request is made or when money moves. Lesson progress, watch events and quiz attempts are kept, because the admin reads them as evidence and a repurchase should resume where the learner stopped. Declining changes nothing.

Consequence: video tracking refuses learners who have no enrollment, so progress stops growing after approval while the history stays visible.
