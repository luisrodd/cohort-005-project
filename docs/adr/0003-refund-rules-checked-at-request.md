# Refund window and watch limit are checked at request time only

The refund window and the watch limit are checked when a learner submits a request, not when an admin decides it. The rules say what a learner may ask for; the admin decides the outcome. We chose this over re-checking at approval, which would mean an approval can be refused for a rule the learner met when they asked.

Consequence: an admin can approve a request made inside the window even if the window has closed by the time they decide.
